⚠️  重要提示
─────────────────────────────────────────────────────────────────────────────
  1. 需要 GitHub Personal Access Token
     访问: https://github.com/settings/tokens
     权限: public_repo, user

  2. API 速率限制
     认证用户: 5000 请求/小时
     建议实现缓存机制

  3. 安全建议
     - 不要硬编码 Token
     - 使用 .env 文件
     - 不要提交 .env 到 Git

  4. 开发环境要求
     - Node.js 18.0+
     - Rust (Tauri)
     - Xcode (iOS)
     - Android Studio (Android)
