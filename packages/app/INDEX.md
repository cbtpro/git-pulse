## ⚡ 常用命令

```bash
# 开发
pnpm dev              # Web/macOS 开发
pnpm tauri ios dev    # iOS 开发

# 编译检查
pnpm type-check       # TypeScript
pnpm build            # 生产构建

# 信息
pnpm tauri info       # 环境诊断
```
