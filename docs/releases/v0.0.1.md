# GitPulse v0.0.1

GitPulse 首次发布，提供 Web、Windows、macOS、Linux、Android 和 iOS 的 GitHub 工作台。

## 功能

- Arco Design 界面与 Lucide 图标；简体中文、繁体中文、英文和日语。
- GitHub 浏览器设备授权、Token 登录、多账号切换及本地加密存储。
- 仓库、用户、组织、主题、代码、提交、Issues/PR 和 GitHub Pages 聚合搜索，支持高级搜索语法、输入法合成、去抖、键盘导航与最近搜索。
- 个人主页、Canvas 2D/3D 贡献图、自定义 Pins、GitHub Pages 搜索和分页。
- 收件箱点击消息时标记已读；主题、渐变毛玻璃、安全区和个人主页展示设置。
- 桌面和移动端交互适配、无障碍阅读与各平台开发脚本。

## 登录与平台修复

- 待完成的 GitHub 授权加密保存；iOS 页面重载后恢复原授权，前后台切换不丢弃验证码，临时网络超时会退避重试。
- 登录组件重新挂载不会取消授权，主动取消或关闭登录弹窗仍会清除授权。
- 修复 Android OAuth 请求的 TLS 初始化问题，补齐 GitHub 查询鉴权。
- iOS 最低支持 18.7.8，并支持本机开发团队与首选真机配置。

## 下载说明

各平台产物以 ZIP 分组，附 SHA256SUMS.txt。Windows 包含 EXE/MSI；macOS 包含 DMG 与应用归档；Linux 包含 DEB/RPM/AppImage；Android 包含 APK/AAB；iOS 包含真机 IPA 和模拟器应用；Web 包含静态站点。

未配置发布签名时，Android 和 iOS 真机产物未签名，需要签名后安装；macOS 使用临时签名，未公证；Windows 未配置发行者签名。Web 浏览器授权需要同源 OAuth 代理，纯静态部署可用 Token 登录。本版本不上传应用商店。

## 验证

本地应用类型检查、127 项应用测试、19 项脚本测试及 Web 生产构建。授权恢复已通过模拟页面重载、后台切换和网络异常的回归测试，并完成浏览器重载后恢复授权和登录状态的回归；尚未完成修复后的 iPhone 浏览器人工授权回归。各平台打包结果以本版本关联的 GitHub Actions 记录为准。
